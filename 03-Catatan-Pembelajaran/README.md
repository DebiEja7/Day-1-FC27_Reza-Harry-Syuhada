## Materi Pembelajaran Day 1

### 1. MBKM dan Kemitraan TIK

MBKM merupakan program Merdeka Belajar
Kampus Merdeka yang memberikan kesempatan
kepada mahasiswa untuk mengembangkan
kemampuan di luar kegiatan perkuliahan.

Bentuk kegiatan MBKM:
- Pertukaran pelajar
- Proyek kemanusiaan
- Magang
- Asistensi mengajar
- Wirausaha
- Proyek independen
- Penelitian atau riset
- KKN

### 2. Building with AI

Prompt engineering merupakan teknik
menyusun instruksi kepada AI agar
menghasilkan jawaban sesuai kebutuhan.

Komponen prompt:
- Role
- Task
- Context
- Format

### 3. Git dan GitHub

Git merupakan sistem version control
untuk mengelola perubahan kode secara lokal.

GitHub merupakan platform berbasis web
untuk menyimpan repository dan berkolaborasi.

### 4. Alur Kerja Git

1. Working Directory
2. Staging Area (git add)
3. Commit (git commit)
4. Sinkronisasi (git push / git pull)
