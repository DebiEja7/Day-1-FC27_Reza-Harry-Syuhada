# Catatan Pembelajaran

Folder ini berisi catatan dan rangkuman materi yang diperoleh selama mengikuti workshop.

## Isi Catatan
- Rangkuman materi workshop.
- Poin-poin penting yang dipelajari.
- Pengetahuan dan pengalaman baru.
- Kendala serta solusi selama kegiatan.

## Tujuan
Membantu peserta memahami kembali materi yang telah disampaikan dan menjadi bahan pembelajaran di kemudian hari.
