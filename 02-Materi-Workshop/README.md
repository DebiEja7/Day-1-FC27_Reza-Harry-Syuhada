# Materi Workshop

Folder ini digunakan untuk menyimpan berbagai materi yang disampaikan selama kegiatan workshop.

## Isi Materi
- Materi pembelajaran workshop.
- File presentasi atau PDF.
- Contoh praktik yang diberikan.
- Referensi pembelajaran tambahan.

## Tujuan
Sebagai tempat penyimpanan materi agar dapat dipelajari kembali setelah kegiatan workshop selesai.
